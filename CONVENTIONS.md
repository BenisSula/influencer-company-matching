# Project Naming Conventions

This document outlines the naming conventions used throughout the influencer-company-matching project to ensure consistency and maintainability.

## Folders
- All lowercase, hyphen-separated
- Examples: `components`, `modules`, `navigation`, `utils`, `user-profile`, `match-service`

## Files
- **React components**: PascalCase.tsx
  - Examples: `ProfileScreen.tsx`, `LoginForm.tsx`, `MatchCard.tsx`
- **Other files**: lowercase with hyphens
  - Examples: `login-form.tsx`, `match-card.tsx`, `api-client.ts`, `user-utils.ts`

## Modules
- Use camelCase
- Examples: `userModule`, `matchModule`, `authModule`

## Constants
- Use UPPER_SNAKE_CASE
- Examples: `API_URL`, `PRIMARY_COLOR`, `MAX_RETRY_ATTEMPTS`
