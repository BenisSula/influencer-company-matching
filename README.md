# Influencer–Company Matching Platform

This repository contains the source code for a mobile-first platform that matches companies with influencers for brand collaborations.

## Vision
To build a scalable, secure, and user-friendly matching system that connects brands and influencers based on audience, values, and campaign needs.

## Tech Stack (Planned)
- Mobile App: React Native (Expo, TypeScript)
- Backend API: NestJS (Node.js, TypeScript)
- Database: PostgreSQL (Prisma ORM)

## Development Approach
- Mobile-first
- Backend-driven architecture
- Modular and scalable design
- Phase-by-phase development

## Status
Phase 0.1 – Project foundation initialized.
